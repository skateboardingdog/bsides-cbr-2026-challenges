# x67 Writeup

It's self-modifying code. `x67_method()` gets changed from `return 0;` to something more complicated.

The easiest way is probably to breakpoint just after `x67_method()` runs and disassemble the new `x67_method()`. The full disassembly is included at the bottom of this writeup.

The code is otherwise fairly straightforward, in particular there are no branches and the accumulator just xors a bunch of checks and verifies that the final result is zero. This means we just need each check to be zero.

Roughly speaking, the code reads 4 bytes from a sliding window, transforms it with `imul` and `xor`, then writes it back. The check is least significant byte. In fact, after the first byte, the remaining 66 bytes all follow the exact same pattern of one imul followed by one xor. So it's possible to do this left to right one byte at a time, and check that the flag format `skbdg{` uniquely satisfies the check so far.

Or you could z3 it or whatever, it ends up the same. The flag is

```
skbdg{6_oF_7_byT3s_iN_e4Ch_in5TruCt10n_i5_Mad3_uP_of_0nLy_6s_or_7s}
```
