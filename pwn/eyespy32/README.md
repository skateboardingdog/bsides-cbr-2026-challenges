======================

- **Category**: pwn
- **Difficulty**: medium

I spy with my little eye...

NOTE: This is a physical challenge. The application and built binary that
runs on the device is provided to you. A QEMU testing environment is also
available, but your exploit must work against the real device to get the
flag! Please come to the admin desk with your laptop when you're ready to
throw your exploit against the real device. We'll set up the environment and
give you credentials for the WiFi AP.
