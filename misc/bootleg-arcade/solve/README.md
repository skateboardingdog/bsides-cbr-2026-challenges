The arcade cabinets on the CTF platform all correspond to a real arcade game:

```
THREAD REVERSE
STREET FIGHTER

WEB SAN
PAC MAN

PWN DOG
DIG DUG

IGNITED CRYPT
INDIANA JONES

AWAKEND MISC
DRAGONS LAIR

GAME LEVELS
TRON LEGACY
```

Their names also perfectly fit what the original arcade game was, and the
non-category word in each game has exactly two shared letters (eigenletters).
Taking these give:

```
RE
AN
DG
II
AN
LE
```

which gives the answer: `RADIAL ENGINE`.
